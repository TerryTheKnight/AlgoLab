# AlgoLab roadmap

## Included in this release

- React, Vite, and TypeScript dashboard with shared navigation.
- Sorting, graph, search, data-structure, complexity, and experiment labs.
- Asymptotic notation, a Merge Sort recursion tree, and an iterative operation counter.
- Thirteen algorithm lessons with Python references and links to interactive demonstrations.
- Automated algorithm regression tests, linting, production builds, and GitHub Pages deployment workflow.
- MIT license, contributor guidance, architecture notes, benchmark methodology, and course-coverage map.

## Follow-on ideas

- Add more recurrence examples and recurrence-relation comparison exercises.
- Add further graph models, directed graphs, and additional shortest-path algorithms.
- Add browser-based accessibility and device testing across a broader set of environments.
- Add optional persistence if users need saved experiments; the current static app intentionally requires no account or server.
